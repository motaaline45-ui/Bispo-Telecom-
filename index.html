Configuração avançada (Client ID)

Cadastre a origem deste app nas origens JavaScript autorizadas do seu cliente OAuth.

Como criar o Client ID (passo a passo)
  1. Crie um projeto no Google Cloud.
  2. Ative a Google Drive API.
  3. Configure a tela de consentimento como Externo e adicione seu e-mail em Usuários de teste.
  4. Em Credenciais, crie ID do cliente OAuth → Aplicativo da Web.
  5. Em Origens JavaScript autorizadas, adicione a origem onde este app será publicado (sem caminho ou barra no final).
  6. Copie o Client ID (termina em .apps.googleusercontent.com) e cole no campo acima.

O backup fica na pasta privada do app no Google Drive. Só este app consegue acessá-lo — ele não aparece na lista normal de arquivos.
